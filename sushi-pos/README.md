# ระบบสารสนเทศเพื่อการจัดการร้านซูชิ 10 บาท

ระบบขายหน้าร้าน (POS) พร้อมระบบสะสมแต้มและโปรโมชันแบบดิจิทัลผ่านเบอร์โทรศัพท์
เขียนด้วย HTML/CSS/JavaScript ล้วน (ไม่ต้องติดตั้ง server หรือฐานข้อมูลเพิ่มเติม)
ข้อมูลถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งาน

## ฟีเจอร์หลัก

1. **ขายหน้าร้าน (POS)**
   - เมนูซูชิ/ของทานเล่น/เครื่องดื่ม แสดงเป็นตะกร้าสินค้า พร้อมค้นหาและกรองตามหมวดหมู่
   - เพิ่ม/ลด/ลบสินค้าในตะกร้า คำนวณยอดเงินอัตโนมัติ ลดความผิดพลาดจากการคิดเงินด้วยมือ
   - ออกใบเสร็จและพิมพ์ใบเสร็จได้ทันที

2. **สมาชิกและสะสมแต้ม (ผูกกับเบอร์โทรศัพท์)**
   - กรอกเบอร์โทรตอนขาย ระบบค้นหา/สร้างสมาชิกใหม่ให้อัตโนมัติ
   - อัตราสะสมแต้มมาตรฐาน: ทุก 10 บาท = 1 แต้ม
   - แลกแต้มเป็นส่วนลดได้ทันทีตอนชำระเงิน (1 แต้ม = 1 บาท)
   - หน้าจัดการสมาชิกแยกต่างหาก ดูประวัติแต้ม ยอดซื้อสะสม จำนวนครั้งที่มาใช้บริการ

3. **โปรโมชันดิจิทัล**
   - ตั้งโปรโมชันได้ 4 รูปแบบ: ส่วนลด %, ส่วนลดจำนวนเงิน, แต้มสะสมคูณพิเศษ, ของแถม
   - กำหนดยอดซื้อขั้นต่ำ เปิด/ปิดการใช้งานได้ตลอดเวลา
   - ระบบเลือกโปรโมชันส่วนลดที่คุ้มค่าที่สุดให้ลูกค้าโดยอัตโนมัติในหน้าขาย

4. **รายงานยอดขาย**
   - ยอดขายวันนี้ จำนวนบิล แต้มที่แจก ยอดขายสะสมทั้งหมด
   - เมนูขายดี 10 อันดับ
   - ลูกค้าประจำเรียงตามยอดซื้อสะสม เพื่อใช้วางแผนกิจกรรมส่งเสริมการขาย

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
หรือจะอัปโหลดขึ้น GitHub Pages เพื่อให้เข้าถึงผ่านลิงก์ออนไลน์ก็ได้ (ดูด้านล่าง)

> ข้อมูลเก็บแบบ local (เบราว์เซอร์ต่อเครื่อง) เหมาะสำหรับสาธิต/ใช้งานเครื่องเดียว
> หากต้องการใช้งานหลายเครื่อง/หลายสาขาพร้อมกัน ควรต่อยอดเป็นระบบที่มีฐานข้อมูลกลาง
> (เช่น Firebase, Supabase หรือ backend ของตัวเอง) ในเวอร์ชันถัดไป

## วิธีอัปโหลดขึ้น GitHub

รันคำสั่งต่อไปนี้ในเครื่องของคุณ (ต้องติดตั้ง Git และมีบัญชี GitHub แล้ว):

```bash
cd sushi-pos
git init
git add .
git commit -m "Initial commit: ระบบขายหน้าร้านและสะสมแต้มร้านซูชิ 10 บาท"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/sushi-pos.git
git push -u origin main
```

### เปิดใช้งานผ่าน GitHub Pages (ไม่เสียค่าใช้จ่าย)

1. ไปที่ repository บน GitHub → **Settings → Pages**
2. ในหัวข้อ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
3. รอสักครู่ ระบบจะสร้างลิงก์ให้ เช่น
   `https://<ชื่อผู้ใช้ของคุณ>.github.io/sushi-pos/`
4. เปิดลิงก์นี้บนคอมพิวเตอร์หรือแท็บเล็ตหน้าร้านเพื่อใช้งานได้ทันที

## แนวทางต่อยอด

- เชื่อมต่อ SMS/LINE Notify เพื่อแจ้งแต้มสะสมและโปรโมชันให้ลูกค้าอัตโนมัติ
- ย้ายข้อมูลจาก localStorage ไปยังฐานข้อมูลกลาง (เช่น Firebase Firestore) เพื่อให้หลายอุปกรณ์ใช้ข้อมูลร่วมกัน
- เพิ่มระบบผู้ใช้งาน/สิทธิ์การเข้าถึงสำหรับพนักงานและเจ้าของร้าน
- เพิ่มรายงานเปรียบเทียบยอดขายรายวัน/รายเดือนแบบกราฟ
